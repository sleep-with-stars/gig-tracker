# 工时与收入记工助手 (Gig Work Hour & Income Tracker)

专为兼职、零工、外卖骑手、小时工与钟点工量身定制的**移动端工时打卡与收入结算 APP**。

---

## 🌟 核心功能特色

1. **三种计费模式（支持全局默认与单日自定义覆盖）**：
   - **计件模式（如送外卖/按件计费）**：当日收入 = 送单量 × 单价 + 补贴 - 扣款
   - **时薪模式（如兼职/钟点工）**：当日收入 = 总工时（精确到小数点后2位） × 时薪 + 补贴 - 扣款
   - **底薪 + 提成模式**：当日收入 = (总工时 × 基础时薪) + (送单量 × 每单提成) + 补贴 - 扣款
   - **单日自定义**：支持任意单日勾选自定义费率（如节假日双倍时薪、特殊单价），不影响全局标准。

2. **打卡计时与记工（首页）**：
   - **打卡计时器**：大按钮一键「开始上班」与「结束下班」，实时秒级跳动与状态指示，持久化防刷新丢失。
   - **支持单日多打卡段**：一天内支持多次打卡（例如上午打卡1次，下午打卡1次），系统自动记录每段起止时间，并在结算时自动累加当天总工时。
   - **手动补录/修改**：如果忘记打卡，可随时点击「补录工时」手动指定起止时间或直接输入工时数。
   - **单量快捷键**：提供 `-1`、`+1`、`+5`、`+10`、`清零` 等快捷加减按钮及直接数字录入。
   - **补贴与扣罚**：支持添加天气补贴、夜班补贴、扣款扣罚及文字备注。

3. **月度日历看板与聚合统计（统计页）**：
   - **月历视图**：每个日期格子清晰展示出工状态、总工时（如 `3.5h`）、送单量（如 `24单`）、当天预估收入（如 `¥120`）。
   - **点击日期查看明细**：弹出底部抽屉查看当天所有打卡段、收入公式、补贴扣款与备注，并可一键载入首页修改或删除。
   - **月度聚合看板**：当月总收入、总工时、总单量、平均时薪（元/小时）、日均收入（元/天）、总出工天数。
   - **月份快速切换**：左右箭头切换月份，支持一键返回当月。

4. **数据存储与多格式导出**：
   - **完全本地化**：基于 LocalStorage / IndexedDB 本地持久存储，零后端依赖，保护隐私，离线秒开。
   - **Excel / CSV 导出**：支持一键导出当月或全部历史报表（带 UTF-8 BOM 编码，Excel 打开不乱码）。
   - **JSON 备份与恢复**：一键导出 JSON 备份文件，支持随时导入恢复。

## 📱 手机端使用与打包指引

### 方式一：PWA 网页直接安装到手机桌面（零门槛，免编译）

本项目已完整配置 PWA（`manifest.json` 与 `sw.js`）。

1. **部署或本地启动**：
   - 可以在局域网或任意静态服务器（如 GitHub Pages、Vercel、Cloudflare Pages）上运行。
   - 浏览器打开访问地址（需使用 `https://` 或 `http://localhost`）。
2. **添加到手机主屏幕**：
   - **Android 手机（Chrome / Edge / 各品牌自带浏览器）**：
     点击浏览器右上角菜单 `⋮` -> 选择 **「添加到主屏幕」** 或 **「安装应用」**。
   - **iPhone / iPad（Safari 浏览器）**：
     点击底部分享按钮（带有向上箭头的方框） -> 下滑选择 **「添加到主屏幕」**。
3. 添加完成后，手机桌面上会生成独立的「记工助手」App 图标，点击即全屏运行，体验与原生 App 完全一致，支持离线使用。

---

### 方式二：使用 Capacitor 打包为 Android 原生 APK 安装包

```bash
# 1. 安装依赖
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android

# 2. 初始化工程
npx cap init "工时记工助手" "com.gigtracker.workhour" --web-dir .
npx cap add android
npx cap sync

# 3. 编译 APK
npx cap open android
```
在 Android Studio 中点击 **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)** 即可。
